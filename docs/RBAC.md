# HRsoft RBAC — Roles × Permissions

_Generated by `npx tsx scripts/gen-rbac-doc.ts` from `src/lib/rbac/permissions.ts`. Do not edit by hand._

## Model

- A **permission** is `module:action`.
- Each role grants a permission at a **scope**: **Self** (own records), **Team** (self + direct and indirect reports, resolved with a recursive CTE on `Employee.managerId`), **All**.
- A user's effective scope for a permission is the **widest** scope across all of their roles.
- Services enforce RBAC with `authorize(actor, permission, { employeeId })` and `scopeFilter(actor, permission)`; the UI only hides what the server already forbids.
- Custom roles can be created in **Settings → Roles & Access**; `SUPER_ADMIN` is immutable.

## Roles

- **SUPER_ADMIN** — Super Admin: Full access to every module and setting.
- **EMPLOYEE** — Employee: Self-service: own profile, attendance, leave, payslips, expenses, tickets, OKRs, timesheets.
- **MANAGER** — Manager: Everything an employee can do, plus team-scoped visibility and approvals for direct and indirect reports.
- **HR_ADMIN** — HR Admin: Owns the employee lifecycle: records, onboarding, attendance, leave, performance, engagement, helpdesk.
- **PAYROLL_ADMIN** — Payroll Admin: Runs payroll, manages salary structures, verifies tax declarations.
- **FINANCE** — Finance: Approves and reimburses expenses, reads payroll totals and project billing.
- **RECRUITER** — Recruiter: Owns the hiring pipeline.
- **IT_ADMIN** — IT Admin: Manages assets, IT helpdesk tickets and API keys.
- **PROJECT_MANAGER** — Project Manager: Manages projects, tasks and approves timesheets across the company.
